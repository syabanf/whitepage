# @cms/openapi

Single source of truth for the company-profile-cms API contract.

## Files

- `openapi.yaml` — the spec (OpenAPI 3.1)
- `generated/client.ts` — TS client types generated by `openapi-typescript` (commit this; do not edit by hand)

## Workflow

```bash
# Regenerate TS types after editing openapi.yaml
pnpm --filter @cms/openapi generate

# Lint the spec
pnpm --filter @cms/openapi lint
```

The Go side uses `oapi-codegen` (configured in `apps/api/`) and reads the same `openapi.yaml`.

## Authentication

- Editor/admin endpoints use cookie-based session auth (`cms_session` cookie).
- Internal endpoints (`/internal/*`) use a bearer service token for renderer-to-API calls.
